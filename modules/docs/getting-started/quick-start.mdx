이 가이드는 Sonamu 프로젝트를 설치한 후 개발 환경을 실행하는 방법을 단계별로 안내합니다.

## 전제 조건

[설치하기](/getting-started/installation) 가이드를 완료하고 프로젝트가 생성되어 있어야 합니다.

## 개발 환경 실행

Sonamu 개발 환경은 다음 세 가지 서버로 구성됩니다:

- **PostgreSQL** - 데이터베이스
- **API 서버** - 백엔드 REST API
- **Web 서버** - 프론트엔드 애플리케이션

추가로 **Sonamu UI**를 실행하여 엔티티를 관리할 수 있습니다.

<Steps>
<Step title="데이터베이스 시작">

프로젝트의 `api` 디렉토리로 이동하여 PostgreSQL 컨테이너를 시작합니다:

```bash
cd my_app/api
pnpm docker:up
```

이 명령어는 Docker Compose를 사용하여 PostgreSQL 데이터베이스를 백그라운드에서 실행합니다.

<Tip>
  데이터베이스가 정상적으로 실행되었는지 확인하려면 `docker ps` 명령어로
  컨테이너 상태를 확인할 수 있습니다.
</Tip>

</Step>

<Step title="API 서버 실행">

같은 `api` 디렉토리에서 개발 서버를 시작합니다:

```bash
pnpm dev
```

서버가 성공적으로 시작되면 다음과 같은 메시지가 표시됩니다:

```
🌲 Server listening on http://localhost:1028
```

API 서버는 Hot Module Replacement(HMR)을 지원하므로 코드 변경 시 자동으로 재시작됩니다.

<Warning>
  이 터미널 창은 계속 열어두어야 합니다. API 서버가 실행 중인 상태를 유지합니다.
</Warning>

</Step>

<Step title="Sonamu UI 실행 (선택사항)">

**새 터미널 창**을 열고 `api` 디렉토리에서 Sonamu UI를 실행합니다:

```bash
cd my_app/api
pnpm sonamu ui
```

Sonamu UI가 시작되면 브라우저에서 http://localhost:2028 로 접속할 수 있습니다.

Sonamu UI에서는 다음 작업을 수행할 수 있습니다:

- 엔티티 생성 및 편집
- 데이터베이스 마이그레이션 관리
- API 엔드포인트 확인
- 데이터베이스 스키마 시각화

<Note>
  Sonamu UI는 개발 중에만 필요합니다. 엔티티를 생성하거나 관리할 때 사용하세요.
</Note>

</Step>

<Step title="Web 서버 실행">

**새 터미널 창**을 열고 `web` 디렉토리로 이동하여 프론트엔드 개발 서버를 시작합니다:

```bash
cd my_app/web
pnpm dev
```

Vite 개발 서버가 시작되면 다음과 같은 메시지가 표시됩니다:

```
  VITE v5.x.x  ready in xxx ms

  ➜  Local:   http://localhost:3028/
  ➜  Network: http://192.168.x.x:3028/
```

Web 서버는 API 서버로의 프록시를 자동으로 설정하므로 `/api/*` 경로로 요청하면 API 서버로 전달됩니다.

</Step>
</Steps>

## 접속 확인

이제 모든 서버가 실행 중입니다. 브라우저에서 다음 URL로 접속할 수 있습니다:

| 서비스    | URL                       | 설명                    |
| --------- | ------------------------- | ----------------------- |
| Web 앱    | http://localhost:3028     | 프론트엔드 애플리케이션 |
| API 서버  | http://localhost:1028/api | REST API 엔드포인트     |
| Sonamu UI | http://localhost:2028     | 엔티티 관리 인터페이스  |

<Check>
  Web 앱(http://localhost:3028)에 접속하여 Sonamu 애플리케이션이 정상적으로
  실행되는지 확인하세요.
</Check>

## 서버 중지

개발을 마치고 서버를 중지하려면:

1. **API 서버와 Web 서버**: 각 터미널에서 `Ctrl + C` 키를 눌러 중지합니다.

2. **Sonamu UI**: 터미널에서 `Ctrl + C` 키를 눌러 중지합니다.

3. **데이터베이스**: `api` 디렉토리에서 다음 명령어를 실행합니다:

```bash
pnpm docker:down
```

<Warning>
  `docker:down` 명령어는 컨테이너를 중지만 하며, 데이터는 보존됩니다.
  데이터베이스를 완전히 초기화하려면 [데이터베이스 관리](/database/management)
  문서를 참고하세요.
</Warning>
