Sonamu is a TypeScript-first fullstack framework that brings end-to-end type safety to your entire application stack.

## Key Features

- 🔒 **End-to-End Type Safety** - From database to frontend
- 🚀 **Auto Code Generation** - Reduce boilerplate with intelligent code generation
- 🎨 **Entity-Driven Development** - Define your data model once, use it everywhere
- ⚡ **Fast Development** - Hot Module Replacement and instant feedback
- 🧪 **Testing First** - Built-in testing utilities and fixtures
