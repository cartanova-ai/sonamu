Context는 Sonamu API 메서드 실행 중에 HTTP 요청과 관련된 정보에 접근할 수 있게 해주는 객체입니다. API 메서드의 파라미터로 주입받아 사용할 수 있으며, AsyncLocalStorage를 통해 관리됩니다.

## 타입 정의

```typescript
type Context = {
  request: FastifyRequest;
  reply: FastifyReply;
  headers: IncomingHttpHeaders;
  createSSE: <T extends ZodObject>(events: T) => ReturnType<typeof createSSEFactory<T>>;
  naiteStore: NaiteStore;
  locale: string;
  files?: UploadedFile[];
} & AuthContext & ContextExtend;
```

The Context type is composed of **Intersection Types (`&`)**:
- Base Context object (request, reply, etc.)
- `AuthContext`: Authentication-related properties (user, passport)
- `ContextExtend`: Project-specific extension properties

This structure allows Context to be extensible while maintaining type safety.

## Context 속성

### request

```typescript
request: FastifyRequest
```

현재 HTTP 요청을 나타내는 Fastify Request 객체입니다. 요청 URL, 메서드, 쿼리 파라미터 등에 접근할 수 있습니다.

### reply

```typescript
reply: FastifyReply
```

현재 HTTP 응답을 나타내는 Fastify Reply 객체입니다. 응답 헤더 설정, 상태 코드 변경 등에 사용할 수 있습니다.

### headers

```typescript
headers: IncomingHttpHeaders
```

HTTP 요청 헤더입니다. `request.headers`와 동일한 값으로, 편의를 위해 제공됩니다.

### createSSE

```typescript
createSSE: <T extends ZodObject>(events: T) => ReturnType<typeof createSSEFactory<T>>
```

Server-Sent Events(SSE) 스트림을 생성하는 함수입니다. Zod 스키마를 사용하여 타입 안전한 이벤트 스트림을 만들 수 있습니다.

**사용 예시:**

```typescript
import { z } from "zod";

class MyModelClass extends BaseModel {
  @api()
  @stream({
    type: "sse",
    events: z.object({
      progress: z.object({ percent: z.number() }),
      complete: z.object({ result: z.string() })
    })
  })
  async processData(ctx: Context) {
    const sse = ctx.createSSE({
      progress: z.object({ percent: z.number() }),
      complete: z.object({ result: z.string() })
    });

    // 진행률 전송
    await sse.send("progress", { percent: 50 });
    
    // 완료 이벤트 전송
    await sse.send("complete", { result: "done" });
    
    return sse.getResponse();
  }
}
```

### naiteStore

```typescript
naiteStore: NaiteStore
```

Naite 테스팅 프레임워크에서 사용하는 저장소입니다. 테스트 중 모킹된 데이터나 스냅샷 정보를 저장하는 용도로 사용됩니다.

### locale

```typescript
locale: string
```

The locale (language setting) of the current request. This property always has a value.

Parses the `Accept-Language` header and automatically selects one of the supported locales. If no match is found, the `defaultLocale` is used.

**Configuration example:**

```typescript
// sonamu.config.ts
export default {
  i18n: {
    defaultLocale: "en",
    supportedLocales: ["en", "ko", "ja"]
  }
} satisfies SonamuConfig;
```

**Usage example:**

```typescript
class PostModelClass extends BaseModel {
  @api({ httpMethod: "GET" })
  async findMany(ctx: Context) {
    const locale = ctx.locale; // "en", "ko", or "ja"

    // Return different responses based on locale
    const posts = await this.getPuri("r")
      .table("posts")
      .where("locale", locale)
      .select("*");

    return posts;
  }
}
```

### files

```typescript
files?: UploadedFile[]
```

List of uploaded files. This property only exists in methods with the `@upload` decorator.

Each file is provided as an `UploadedFile` object with various methods for file processing.

**UploadedFile key properties and methods:**

```typescript
interface UploadedFile {
  // File information
  filename: string;       // File name
  mimetype: string;       // MIME type (e.g., "image/png", "application/pdf")
  size: number;           // File size in bytes
  extname: string;        // Extension (e.g., "png", "pdf")

  // File processing methods
  md5(): Promise<string>;                    // Generate MD5 hash
  saveToDisk(key: string): Promise<string>;  // Save file and return URL
  toBuffer(): Promise<Buffer>;               // Read as Buffer
}
```

**Basic usage example:**

```typescript
class FileModelClass extends BaseModel {
  @upload({ limits: { files: 10 } })
  async upload(): Promise<{ files: SonamuFile[] }> {
    const { files } = Sonamu.getContext();

    if (!files || files.length === 0) {
      throw new BadRequestException("No files uploaded");
    }

    const processedFiles = await Promise.all(
      files.map(async (file) => {
        const md5 = await file.md5();
        const key = `${md5}.${file.extname}`;
        return {
          name: file.filename,
          url: await file.saveToDisk(key),
          mime_type: file.mimetype,
          size: file.size,
        };
      })
    );

    return { files: processedFiles };
  }
}
```

**Usage with parameters:**

```typescript
class FileModelClass extends BaseModel {
  @upload({ limits: { files: 5 } })
  async uploadWithCategory(params: { category: string }): Promise<{
    category: string;
    files: SonamuFile[];
  }> {
    const { files } = Sonamu.getContext();
    const { category } = params;

    if (!files || files.length === 0) {
      throw new BadRequestException("No files uploaded");
    }

    return {
      category,
      files: await Promise.all(
        files.map(async (file) => ({
          name: file.filename,
          url: await file.saveToDisk(`${category}/${await file.md5()}`),
          mime_type: file.mimetype,
          size: file.size,
        }))
      ),
    };
  }
}
```

**Image processing example:**

```typescript
import sharp from "sharp";

class ImageModelClass extends BaseModel {
  @upload({ limits: { files: 1 } })
  async uploadThumbnail(): Promise<{ url: string }> {
    const { files } = Sonamu.getContext();

    if (!files || files.length === 0) {
      throw new BadRequestException("No image uploaded");
    }

    const file = files[0];

    // Read as Buffer and process image
    const buffer = await file.toBuffer();
    const thumbnail = await sharp(buffer)
      .resize(200, 200)
      .jpeg({ quality: 80 })
      .toBuffer();

    // Save processed image
    const disk = Sonamu.storage.use();
    const key = `thumbnails/${await file.md5()}.jpg`;
    await disk.put(key, thumbnail);

    return { url: await disk.getUrl(key) };
  }
}
```

<Info>
**File Upload Handling**:
- Must be used with the `@upload` decorator
- Files are automatically saved to the configured storage
- The order of the `files` array matches the order they were sent in the form
- See [@upload decorator](/api-reference/decorators/upload) documentation for more details
</Info>

### AuthContext 속성

Context는 [AuthContext](/api-reference/context/auth-context)의 속성들도 포함합니다:

- `user`: 현재 인증된 사용자 정보
- `passport`: 인증 관련 메서드 (login, logout)

## Context 확장

프로젝트에서 Context에 커스텀 속성을 추가하려면 `ContextExtend` 인터페이스를 확장할 수 있습니다:

```typescript
// src/types.ts
declare module "sonamu" {
  interface ContextExtend {
    customProperty: string;
    helperMethod: () => void;
  }
}
```

이렇게 확장된 속성은 `contextProvider`를 통해 주입할 수 있습니다:

```typescript
// sonamu.config.ts
export default {
  server: {
    apiConfig: {
      contextProvider: async (baseContext) => {
        return {
          ...baseContext,
          customProperty: "custom value",
          helperMethod: () => console.log("helper")
        };
      }
    }
  }
} satisfies SonamuConfig;
```
