AuthContext is part of Context, providing user authentication state and authentication-related methods. It is implemented based on Fastify Passport.

## Type Definition

```typescript
type AuthContext = {
  user: PassportUser | null;
  passport: {
    login: (user: PassportUser) => Promise<void>;
    logout: () => void;
  };
};
```

## Properties

### user

```typescript
user: PassportUser | null
```

Current authenticated user information. Returns `null` if not logged in.

The `PassportUser` type is provided by `@fastify/passport` and can be customized for your project.

**Usage Example:**

```typescript
class UserModelClass extends BaseModel {
  @api()
  async getMyProfile(ctx: Context) {
    if (!ctx.user) {
      throw new UnauthorizedException("Login required");
    }

    return {
      id: ctx.user.id,
      email: ctx.user.email,
      name: ctx.user.name
    };
  }
}
```

### passport.login

```typescript
login: (user: PassportUser) => Promise<void>
```

Logs in a user. Stores user information in the session, making it accessible via `ctx.user` in subsequent requests.

**Usage Example:**

```typescript
class AuthModelClass extends BaseModel {
  @api()
  async login(
    ctx: Context,
    email: string,
    password: string
  ) {
    // User authentication logic
    const user = await this.validateCredentials(email, password);

    if (!user) {
      throw new UnauthorizedException("Incorrect email or password");
    }

    // Store user information in session
    await ctx.passport.login(user);

    return { success: true, user };
  }

  private async validateCredentials(email: string, password: string) {
    // Implement actual authentication logic
    const user = await this.findByEmail(email);
    if (!user) return null;

    const isValid = await bcrypt.compare(password, user.passwordHash);
    return isValid ? user : null;
  }
}
```

### passport.logout

```typescript
logout: () => void
```

Logs out the current user. Removes user information from the session.

**Usage Example:**

```typescript
class AuthModelClass extends BaseModel {
  @api()
  async logout(ctx: Context) {
    ctx.passport.logout();
    return { success: true, message: "Logged out successfully" };
  }
}
```

## Configuration

To use AuthContext, you need to configure authentication in `sonamu.config.ts`.

### Basic Configuration

```typescript
// sonamu.config.ts
export default {
  server: {
    plugins: {
      // Session plugin required
      session: {
        secret: process.env.SESSION_SECRET || "your-secret-key-here",
        cookie: {
          maxAge: 1000 * 60 * 60 * 24 * 7, // 7 days
        }
      }
    },
    auth: true // Use default serialization/deserialization
  }
} satisfies SonamuConfig;
```

### Custom Serialization/Deserialization

You can customize how user information is stored in and restored from the session:

```typescript
// sonamu.config.ts
export default {
  server: {
    plugins: {
      session: {
        secret: process.env.SESSION_SECRET || "your-secret-key-here",
      }
    },
    auth: {
      userSerializer: async (user, request) => {
        // Return only minimal information to store in session
        return { id: user.id };
      },
      userDeserializer: async (serialized, request) => {
        // Reconstruct full user object from session data
        const user = await UserModel.findById(serialized.id);
        return user;
      }
    }
  }
} satisfies SonamuConfig;
```

## Access Control with Guards

To require authentication for API methods, use the `guards` option:

```typescript
class UserModelClass extends BaseModel {
  @api({ guards: ["user"] })
  async getMyData(ctx: Context) {
    // guards: ["user"] ensures ctx.user is available
    return this.findById(ctx.user!.id);
  }

  @api({ guards: ["admin"] })
  async getAllUsers(ctx: Context) {
    // guards: ["admin"] restricts access to admins only
    return this.findAll();
  }
}
```

Implement guard handling logic in `guardHandler`:

```typescript
// sonamu.config.ts
import { Sonamu } from "sonamu";
import type { GuardKey } from "sonamu";
import type { FastifyRequest } from "fastify";

export default {
  api: {
    apiConfig: {
      guardHandler: (guard: GuardKey, request: FastifyRequest, api) => {
        // Get user information from Sonamu Context
        const context = Sonamu.getContext();

        if (guard === "user" && !context.user) {
          throw new UnauthorizedException("Login required");
        }

        if (guard === "admin" && (!context.user || !context.user.isAdmin)) {
          throw new UnauthorizedException("Admin permission required");
        }

        return true;
      }
    }
  }
} satisfies SonamuConfig;
```

<Info>
`guardHandler` runs inside AsyncLocalStorage, so you can access the current request's Context via `Sonamu.getContext()`. Use `context.user` instead of accessing `user` directly from the `request` object.
</Info>

## Extending PassportUser Type

You can extend the `PassportUser` type to match your project's user information structure:

```typescript
// src/types.ts
declare module "fastify" {
  interface PassportUser {
    id: number;
    email: string;
    name: string;
    isAdmin: boolean;
    createdAt: Date;
  }
}
```
