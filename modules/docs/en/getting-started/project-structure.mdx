<Accordion title="Key File Descriptions">

**package.json**

- Backend dependency management
- npm scripts: `dev`, `build`, `test`, `docker:up/down`, `dump`, `seed`, etc.

**tsconfig.json**

- Main TypeScript compiler configuration
- `tsconfig.schemas.json`: Dedicated for Zod schema generation
- `tsconfig.types.json`: Dedicated for type definition generation

**vite.config.ts**

- Sonamu UI development server configuration (`pnpm sonamu ui`)
- HMR (Hot Module Replacement) configuration

**.env**

- Database connection information
- Project configuration variables
- Auto-generated when running `pnpm create sonamu`

</Accordion>

<Note>
**Entity File Creation Process**

Files in the `application/{entity}/` folder are created when you create an entity through Sonamu UI and scaffold:

- **{entity}.entity.json**: Auto-generated when defining entity in Sonamu UI
- **{entity}.model.ts**: Generated via `pnpm scaffold model` or Sonamu UI's Scaffolding tab
- **{entity}.types.ts**: Auto-generated when saving entity
- **{entity}.model.test.ts**: Generated via `pnpm scaffold model_test` or Sonamu UI's Scaffolding tab (optional)

When you first create a project, the `application/` folder is empty. The folder is created when you create your first entity.
</Note>

<Accordion title="Key Directory Descriptions">

**application/**

- Auto-created when creating the first entity
- Separate directory for each entity
- Example: `User` entity → `application/user/` directory

**application/{entity}/{entity}.entity.json**

- Entity definition file
- Created in Sonamu UI
- Source of database schema

**application/{entity}/{entity}.model.ts**

- Business logic implementation
- API endpoint definitions (`@api` decorator)
- File you write directly

**application/{entity}/{entity}.types.ts**

- TypeScript type definitions
- Zod validation schemas
- Auto-generated but extensible
- Shared with frontend

**application/sonamu.generated.ts**

- Auto-generated Base schemas for all entities
- Enum types and label definitions
- Do not modify directly

**testing/**

- Vitest test environment configuration
- Fixture data management
- Test utilities

</Accordion>

<Accordion title="Key File Descriptions">

**docker-compose.yml**

- PostgreSQL + pgvector image
- Container name, port, environment variable configuration
- Run with `pnpm docker:up`

**fixtures/init.sql**

- Database initial setup
- Extension installation (pgvector, etc.)
- Auto-generated when running `pnpm create sonamu`

**dumps/**

- SQL files generated by `pnpm dump` command
- Data backup storage

**scripts/**

- `dump.sh`: Backs up current DB data to dumps/
- `seed.sh`: Restores data from dumps/ to DB

</Accordion>

### Role of Each File

<CodeGroup>
```json title="user.entity.json"
{
  "properties": [
    {
      "name": "id",
      "type": "int",
      "isPrimary": true
    },
    {
      "name": "email",
      "type": "varchar"
    },
    {
      "name": "name",
      "type": "varchar"
    }
  ]
}
```

```typescript title="user.model.ts"
// File you write directly
import { BaseModel } from "sonamu";

export class UserModel extends BaseModel {
  @api({ httpMethod: "GET" })
  async findById(id: number): Promise<User> {
    // Business logic
  }
}
```

```typescript title="user.types.ts"
// Auto-generated + extensible
import { z } from "zod";
import { UserBaseSchema } from "../sonamu.generated";

// Base type (auto-generated)
export type User = z.infer<typeof UserBaseSchema>;

// Extensible custom types
export const UserSaveParams = UserBaseSchema.partial({
  id: true,
  created_at: true,
});
export type UserSaveParams = z.infer<typeof UserSaveParams>;
```

```typescript title="sonamu.generated.ts"
// Auto-generated - do not modify directly
export const UserBaseSchema = z.object({
  id: z.number(),
  email: z.string(),
  name: z.string(),
  created_at: z.date(),
});

export const UserOrderBy = z.enum(["id-desc", "name-asc"]);
export type UserOrderBy = z.infer<typeof UserOrderBy>;
```

```typescript title="UserService.ts (web)"
// Auto-generated
export class UserService {
  static async findById(id: number): Promise<User> {
    const res = await axios.get(`/api/users/${id}`);
    return res.data;
  }
}
```

</CodeGroup>

## Key Work Locations During Development

| Task                | Location                                              | Method         |
| ------------------- | ----------------------------------------------------- | -------------- |
| Entity Definition   | `api/src/application/{entity}/{entity}.entity.json`   | Sonamu UI      |
| Business Logic      | `api/src/application/{entity}/{entity}.model.ts`      | Manual writing |
| Custom Types        | `api/src/application/{entity}/{entity}.types.ts`      | Manual extension |
| API Endpoints       | `@api` decorator in Model file                        | Manual writing |
| Database Config     | `api/src/sonamu.config.ts`                            | Manual writing |
| Server Config       | `api/src/sonamu.config.ts`                            | Manual writing |
| Writing Tests       | `api/src/application/{entity}/{entity}.model.test.ts` | Manual writing |
| Page Components     | `web/src/pages/`                                      | Manual writing |
| Common Components   | `web/src/admin-common/`                               | Manual writing |

<Warning>
  **Auto-generated File Cautions** - `sonamu.generated.ts`: Never modify - `{Entity}Service.ts`: Never modify - `{entity}.types.ts`: Extension is possible but do not modify auto-generated parts
</Warning>
