Sonamu는 `sonamu.config.ts`를 import하기 전에 API 패키지 루트의 dotenv 파일을 읽습니다. 공통
기본값은 `.env`, 환경별 값은 `.env.<environment>`, 머신별 로컬 override는 `.env.local`에 둡니다.

<Warning>
  실제 비밀값이 들어 있는 `.env` 파일은 커밋하지 마세요. 예시나 템플릿 파일만 커밋하세요.
</Warning>

## 로딩 순서

현재 `NODE_ENV`에 대해 Sonamu는 다음 순서로 값을 적용합니다.

1. `.env`
2. `.env.${NODE_ENV}`
3. `.env.local`
4. export된 process 환경변수

뒤에 오는 값이 앞의 값을 덮습니다. `NODE_ENV`가 없으면 `development`를 사용합니다. 허용 값은
`test`, `development`, `staging`, `production`입니다.

## 파일 구조

```bash
packages/api/.env
packages/api/.env.development
packages/api/.env.staging
packages/api/.env.production
packages/api/.env.test
packages/api/.env.local
```

현재 환경의 파일이 있다면 공통 `.env`는 없어도 됩니다. 단, `.env` 또는 `.env.${NODE_ENV}` 중
하나는 있어야 합니다.

## 공통 값

```bash title=".env"
# 공통 기본값
PROJECT_NAME=MyProject
CONTAINER_NAME=myproject-postgres

# DB 기본값. 환경별 파일에서 필요한 값을 덮어쓸 수 있습니다.
SONAMU_DB_HOST=127.0.0.1
SONAMU_DB_PORT=5432
SONAMU_DB_USER=postgres
SONAMU_DB_PASSWORD=your-db-password

# 비밀값과 외부 서비스
SESSION_SECRET=your-session-secret
SESSION_SALT=your-session-salt
OPENAI_API_KEY=your-openai-api-key
```

## sonamu.config.ts

`sonamu.config.ts`에서는 `process.env`를 그대로 읽을 수 있습니다. Sonamu는 config 파일을
import하기 전에 현재 환경 값을 먼저 로드합니다.

```typescript title="sonamu.config.ts"
import { defineConfig } from "sonamu";

export default defineConfig({
  projectName: process.env.PROJECT_NAME ?? "MyProject",
  database: {
    database: "pg",
    defaultOptions: {
      pool: {
        min: 1,
        max: 10,
      },
    },
  },
});
```

제거된 `database.name` 또는 `database.environments` 필드는 사용하지 마세요. 데이터베이스
이름과 환경별 연결값은 이제 `SONAMU_DB_*` 변수와 `projectName`에서 결정됩니다.

## 전환 팁

- `DB_HOST`, `DB_PORT`, `DB_USER`, `DB_PASSWORD`, `DATABASE_NAME`은 각각
  `SONAMU_DB_HOST`, `SONAMU_DB_PORT`, `SONAMU_DB_USER`, `SONAMU_DB_PASSWORD`,
  `SONAMU_DB_NAME`으로 바꾸세요.
- 읽기 전용 replica는 `SONAMU_DB_READONLY_*`를 사용합니다. 없는 read-only 필드는 현재 환경의
  main DB 값을 사용합니다.
- fixture DB에는 `SONAMU_DB_FIXTURE_*`를 사용합니다.
- 공통 파일과 환경별 파일 다음에 적용할 로컬 override는 `.env.local`에 둡니다.
