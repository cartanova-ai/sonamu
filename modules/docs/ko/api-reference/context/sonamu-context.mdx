Context는 Sonamu API 메서드 실행 중에 HTTP 요청과 관련된 정보에 접근할 수 있게 해주는 객체입니다. API 메서드의 파라미터로 주입받아 사용할 수 있으며, AsyncLocalStorage를 통해 관리됩니다.

## 타입 정의

```typescript
type Context = {
  request: FastifyRequest;
  reply: FastifyReply;
  headers: IncomingHttpHeaders;
  createSSE: <T extends ZodObject>(events: T) => ReturnType<typeof createSSEFactory<T>>;
  naiteStore: NaiteStore;
  locale: string;
  files?: UploadedFile[];
} & AuthContext & ContextExtend;
```

Context 타입은 **교차 타입(Intersection Type, `&`)**으로 구성됩니다:
- 기본 Context 객체 (request, reply 등)
- `AuthContext`: 인증 관련 속성 (user, passport)
- `ContextExtend`: 프로젝트별 확장 속성

이러한 구조 덕분에 Context는 타입 안전성을 유지하면서 확장 가능합니다.

## Context 속성

### request

```typescript
request: FastifyRequest
```

현재 HTTP 요청을 나타내는 Fastify Request 객체입니다. 요청 URL, 메서드, 쿼리 파라미터 등에 접근할 수 있습니다.

### reply

```typescript
reply: FastifyReply
```

현재 HTTP 응답을 나타내는 Fastify Reply 객체입니다. 응답 헤더 설정, 상태 코드 변경 등에 사용할 수 있습니다.

### headers

```typescript
headers: IncomingHttpHeaders
```

HTTP 요청 헤더입니다. `request.headers`와 동일한 값으로, 편의를 위해 제공됩니다.

### createSSE

```typescript
createSSE: <T extends ZodObject>(events: T) => ReturnType<typeof createSSEFactory<T>>
```

Server-Sent Events(SSE) 스트림을 생성하는 함수입니다. Zod 스키마를 사용하여 타입 안전한 이벤트 스트림을 만들 수 있습니다.

**사용 예시:**

```typescript
import { z } from "zod";

class MyModelClass extends BaseModel {
  @api()
  @stream({
    type: "sse",
    events: z.object({
      progress: z.object({ percent: z.number() }),
      complete: z.object({ result: z.string() })
    })
  })
  async processData(ctx: Context) {
    const sse = ctx.createSSE({
      progress: z.object({ percent: z.number() }),
      complete: z.object({ result: z.string() })
    });

    // 진행률 전송
    await sse.send("progress", { percent: 50 });
    
    // 완료 이벤트 전송
    await sse.send("complete", { result: "done" });
    
    return sse.getResponse();
  }
}
```

### naiteStore

```typescript
naiteStore: NaiteStore
```

Naite 테스팅 프레임워크에서 사용하는 저장소입니다. 테스트 중 모킹된 데이터나 스냅샷 정보를 저장하는 용도로 사용됩니다.

### locale

```typescript
locale: string
```

현재 요청의 locale(언어 설정)입니다. 항상 값이 존재합니다.

`Accept-Language` 헤더를 파싱하여 지원하는 locale 중 하나를 자동으로 선택하며, 일치하는 locale이 없으면 `defaultLocale`이 사용됩니다.

**설정 예시:**

```typescript
// sonamu.config.ts
export default {
  i18n: {
    defaultLocale: "ko",
    supportedLocales: ["ko", "en", "ja"]
  }
} satisfies SonamuConfig;
```

**사용 예시:**

```typescript
class PostModelClass extends BaseModel {
  @api({ httpMethod: "GET" })
  async findMany(ctx: Context) {
    const locale = ctx.locale; // "ko", "en", "ja" 중 하나

    // locale에 따라 다른 응답
    const posts = await this.getPuri("r")
      .table("posts")
      .where("locale", locale)
      .select("*");

    return posts;
  }
}
```

### files

```typescript
files?: UploadedFile[]
```

업로드된 파일 목록입니다. `@upload` 데코레이터가 적용된 메서드에서만 존재합니다.

각 파일은 `UploadedFile` 객체로 제공되며, 파일 처리를 위한 다양한 메서드를 제공합니다.

**UploadedFile 주요 속성 및 메서드:**

```typescript
interface UploadedFile {
  // 파일 정보
  filename: string;       // 파일명
  mimetype: string;       // MIME 타입 (예: "image/png", "application/pdf")
  size: number;           // 파일 크기 (bytes)
  extname: string;        // 확장자 (예: "png", "pdf")

  // 파일 처리 메서드
  md5(): Promise<string>;                    // MD5 해시 생성
  saveToDisk(key: string): Promise<string>;  // 파일 저장 후 URL 반환
  toBuffer(): Promise<Buffer>;               // Buffer로 읽기
}
```

**기본 사용 예시:**

```typescript
class FileModelClass extends BaseModel {
  @upload({ limits: { files: 10 } })
  async upload(): Promise<{ files: SonamuFile[] }> {
    const { files } = Sonamu.getContext();

    if (!files || files.length === 0) {
      throw new BadRequestException("파일이 업로드되지 않았습니다");
    }

    const processedFiles = await Promise.all(
      files.map(async (file) => {
        const md5 = await file.md5();
        const key = `${md5}.${file.extname}`;
        return {
          name: file.filename,
          url: await file.saveToDisk(key),
          mime_type: file.mimetype,
          size: file.size,
        };
      })
    );

    return { files: processedFiles };
  }
}
```

**파라미터와 함께 사용:**

```typescript
class FileModelClass extends BaseModel {
  @upload({ limits: { files: 5 } })
  async uploadWithCategory(params: { category: string }): Promise<{
    category: string;
    files: SonamuFile[];
  }> {
    const { files } = Sonamu.getContext();
    const { category } = params;

    if (!files || files.length === 0) {
      throw new BadRequestException("파일이 업로드되지 않았습니다");
    }

    return {
      category,
      files: await Promise.all(
        files.map(async (file) => ({
          name: file.filename,
          url: await file.saveToDisk(`${category}/${await file.md5()}`),
          mime_type: file.mimetype,
          size: file.size,
        }))
      ),
    };
  }
}
```

**이미지 처리 예시:**

```typescript
import sharp from "sharp";

class ImageModelClass extends BaseModel {
  @upload({ limits: { files: 1 } })
  async uploadThumbnail(): Promise<{ url: string }> {
    const { files } = Sonamu.getContext();

    if (!files || files.length === 0) {
      throw new BadRequestException("이미지가 업로드되지 않았습니다");
    }

    const file = files[0];

    // Buffer로 읽어서 이미지 처리
    const buffer = await file.toBuffer();
    const thumbnail = await sharp(buffer)
      .resize(200, 200)
      .jpeg({ quality: 80 })
      .toBuffer();

    // 처리된 이미지 저장
    const disk = Sonamu.storage.use();
    const key = `thumbnails/${await file.md5()}.jpg`;
    await disk.put(key, thumbnail);

    return { url: await disk.getUrl(key) };
  }
}
```

<Info>
**파일 업로드 처리**:
- `@upload` 데코레이터와 함께 사용해야 합니다
- 파일은 설정된 storage에 자동으로 저장됩니다
- `files` 배열의 순서는 폼에서 전송한 순서와 동일합니다
- 자세한 내용은 [@upload 데코레이터](/api-reference/decorators/upload) 문서를 참고하세요
</Info>

### AuthContext 속성

Context는 [AuthContext](/api-reference/context/auth-context)의 속성들도 포함합니다:

- `user`: 현재 인증된 사용자 정보
- `passport`: 인증 관련 메서드 (login, logout)

## Context 확장

프로젝트에서 Context에 커스텀 속성을 추가하려면 `ContextExtend` 인터페이스를 확장할 수 있습니다:

```typescript
// src/types.ts
declare module "sonamu" {
  interface ContextExtend {
    customProperty: string;
    helperMethod: () => void;
  }
}
```

이렇게 확장된 속성은 `contextProvider`를 통해 주입할 수 있습니다:

```typescript
// sonamu.config.ts
export default {
  server: {
    apiConfig: {
      contextProvider: async (baseContext) => {
        return {
          ...baseContext,
          customProperty: "custom value",
          helperMethod: () => console.log("helper")
        };
      }
    }
  }
} satisfies SonamuConfig;
```
