Sonamu UI는 **Entity, Migration, Scaffolding, Fixture 관리를 위한 웹 기반 개발 도구**입니다. CLI로 수행하던 작업들을 시각적인 인터페이스로 더 쉽게 할 수 있으며, 테스트 결과 확인과 CDD 계약 관리 기능도 제공합니다.

## Sonamu UI란?

Sonamu UI는 다음 기능을 제공합니다:

| 기능             | 설명                                       | CLI 대체           |
| ---------------- | ------------------------------------------ | ------------------ |
| **Entity 관리**  | Entity 생성, 수정, 삭제                    | `pnpm sonamu stub entity` |
| **DB Migration** | 마이그레이션 생성 및 실행                  | `pnpm sonamu migrate`     |
| **Scaffolding**  | Model, 테스트 자동 생성                    | `pnpm sonamu scaffold`    |
| **Fixture**      | 테스트 데이터 관리                         | `pnpm sonamu fixture`     |
| **i18n**         | 국제화 문자열 관리                         | 수동 편집          |
| **Tasks**        | 워크플로우 실행 모니터링                   | -                  |
| **Test Results** | 테스트 실행 결과 확인                      | -                  |
| **CDD**          | Contract-Driven Development 계약/스펙 관리 | -                  |

## 실행 방법

### 개발 환경에서 실행

Sonamu UI는 **API 서버에 내장**되어 있습니다. 별도의 명령어가 필요 없습니다.

```bash
# API 서버 실행
cd api
pnpm dev
```

API 서버가 실행되면 Sonamu UI가 자동으로 함께 제공됩니다.

**기본 URL**: `http://localhost:34900/sonamu-ui`

<Info>Sonamu UI는 별도의 포트 없이 **API 서버의 `/sonamu-ui` 경로**에서 제공됩니다.</Info>

### 일반적인 개발 워크플로우

```bash
# API 서버 실행 (Sonamu UI 포함)
cd api
pnpm dev

# 브라우저에서 접속
# http://localhost:34900/sonamu-ui
```

### 접근 보호

Sonamu UI는 로컬 개발 서버(`development`·`test` 환경)에서만 열리며, 다른 웹페이지가 개발자 PC의 UI API를 호출하지 못하도록 요청을 검사합니다.

- 서버가 `/sonamu-ui`의 HTML에 프로세스마다 새로 만드는 접근 토큰을 넣고, UI는 API를 호출할 때 이 토큰을 `X-Sonamu-UI-Token` 헤더로 보냅니다. URL에 토큰을 붙일 필요는 없지만, 서버를 재시작했다면 UI를 새로고침하세요. `/sonamu-ui/index.html`처럼 파일 경로로 직접 열면 토큰이 들어가지 않습니다.
- `/sonamu-ui/api/**`를 직접 호출하는 도구도 현재 HTML의 `sonamu-ui-token` meta 태그에 든 토큰을 같은 헤더로 보내야 합니다. 토큰이 없거나 틀리면 401, 토큰이 맞아도 다른 출처에서 온 요청이면 403입니다.
- 에디터를 실행하는 `tools/openVscode`, `tools/openEditor`, `cdd/openSource`, `cdd/editContent`는 `Content-Type: application/json`과 `X-Sonamu-UI: 1` 헤더를 붙인 같은 출처의 POST 요청만 받고, 나머지는 403으로 거부합니다.
- `tools/openVscode`에 `absPath`를 넘기면 앱 루트(API 디렉토리의 상위 디렉토리) 아래에 실제로 있는 파일만 엽니다. 앱 루트 밖 경로와 그곳을 가리키는 심볼릭 링크, 디렉토리, 없는 파일은 400으로 거부합니다.
- `Host` 헤더가 `localhost`, `*.localhost`, IP 주소, `server.listen.host`·`server.baseUrl`의 호스트 이름, 또는 `server.devAllowedHosts`에 지정한 호스트 이름이 아닌 요청은 403입니다. 별칭 도메인이나 터널로 접속하려면 그 호스트 이름을 [`server.devAllowedHosts`](/ko/configuration/sonamu-config/server#devallowedhosts)에 지정하세요.

## 인터페이스 구조

<Frame caption="Sonamu UI 전체 화면">
  <img src="/images/sonamuUI-created-entity.png" alt="Sonamu UI 전체 화면" />
</Frame>

Sonamu UI는 크게 세 가지 영역으로 구성됩니다:

### 1. Global Navigation Bar (GNB)

화면 상단에 위치하며 주요 기능에 빠르게 접근할 수 있습니다.

| 메뉴              | 기능                     |
| ----------------- | ------------------------ |
| **Entities**      | Entity 생성 및 편집      |
| **DB Migration**  | 마이그레이션 관리        |
| **Scaffolding**   | Model/Test 코드 생성     |
| **Fixture**       | 테스트 데이터 관리       |
| **i18n**          | 국제화 문자열 관리       |
| **Tasks**         | 워크플로우 실행 모니터링 |
| **Test Results**  | 테스트 실행 결과 확인    |
| **CDD**           | CDD 계약/스펙 관리       |
| **Search** (`⌘K`) | 전체 검색                |

### 2. Sidebar

화면 왼쪽에 위치하며 현재 선택한 메뉴의 항목 목록을 표시합니다.

- **Entities 탭**: 모든 Entity 목록 표시
- **Migrations 탭**: 마이그레이션 파일 목록
- **하단 버튼**: 새 항목 추가 버튼 (예: New Entity)

### 3. Main Content Area

화면 중앙의 넓은 영역으로 선택한 항목의 상세 정보를 표시하고 편집합니다.

- Entity 속성 편집
- 마이그레이션 미리보기
- 코드 생성 옵션 등

| ------------------------------- | -------------- |
