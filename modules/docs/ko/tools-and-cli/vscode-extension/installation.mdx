Sonamu 개발을 위한 VS Code 확장을 설치하는 방법입니다.

## Marketplace에서 설치

[VS Code Marketplace](https://marketplace.cursorapi.com/items/?itemName=CartaNova.sonamu)에서 직접 설치할 수 있습니다.

1. VS Code에서 Extensions 탭 열기 (Cmd+Shift+X)
2. "Sonamu" 검색
3. Install 버튼 클릭

## 직접 빌드하여 설치

소스코드를 직접 빌드하여 설치할 수도 있습니다:

```bash
cd ~/Projects/vscode-sonamu
pnpm install && pnpm build
cd packages/extension && pnpm package
code --install-extension sonamu-*.vsix
```

### 업데이트

이미 설치된 Extension을 업데이트하려면 `--force` 옵션을 추가합니다:

```bash
code --install-extension sonamu-*.vsix --force
```

## 활성화 확인

Extension이 제대로 설치되면 워크스페이스에 `sonamu.config.ts` 파일이 있을 때 자동으로 활성화됩니다.

활성화 여부는 다음과 같이 확인할 수 있습니다:

1. Command Palette 열기 (Cmd+Shift+P)
2. "Sonamu" 입력
3. Sonamu 관련 명령어들이 표시되는지 확인
