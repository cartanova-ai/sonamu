Sonamu는 개발자 경험을 최우선으로 설계되었습니다.

## HMR (Hot Module Replacement)

코드를 수정하면 **서버 재시작 없이 즉시 반영**됩니다. Entity, Model, API 어디를 수정하든 2초면 충분합니다.

```bash
# 전통적 방식: Entity 수정 → 서버 재시작 → 30초 대기
# Sonamu 방식: Entity 수정 → 저장 → 2초 후 반영 ✅
```

```bash
# 콘솔 출력 예시
🔄 Invalidated:
- src/application/user/user.model.ts (with 8 APIs)

✅ All files are synced!
```

하루에 50번 수정한다면? 전통적 방식은 25분 낭비, Sonamu는 1.7분입니다.

## 빠른 피드백 루프

Entity 변경 → 타입/스키마 자동 생성 → API 재등록 → 프론트엔드 Service 업데이트까지 **모든 것이 자동**입니다.

```mermaid
graph LR
    A[Entity 변경] --> B[타입 생성]
    B --> C[Zod 스키마]
    C --> D[API 재등록]
    D --> E[Service 업데이트]
    
    style A fill:#4f46e5,color:#fff
    style E fill:#10b981,color:#fff
```

### Syncer가 하는 일

1. **파일 변경 감지**: chokidar로 파일시스템 감시
2. **ESM 캐시 무효화**: 변경된 모듈과 의존성 캐시 제거
3. **코드 자동 생성**: 타입, 스키마, Service 파일 생성
4. **모듈 재로드**: 최신 코드로 재로드
5. **API 재등록**: 변경된 API 엔드포인트 재등록
