## Sonamu에 오신 것을 환영합니다

**Sonamu**는 **Node.js**/**TypeScript** 기반의 **풀스택 프레임워크**입니다.

Fastify 기반의 고성능 백엔드 서버와 엔티티 중심 개발 방식을 통해, 프론트엔드와 백엔드가 타입스크립트라는 동일한 언어를 사용하는 장점을 극대화합니다.

## 핵심 특징

<AccordionGroup>
  <Accordion title="런타임 타입 검증">
    엔티티 정의를 기반으로 Zod 스키마를 자동 생성하며, `@api` 데코레이터가 적용된 메서드의 파라미터를 자동으로 검증합니다.
  </Accordion>
  
  <Accordion title="E2E Type-safety">
    단일 소스(엔티티 정의)에서 출발하여 백엔드와 프론트엔드의 타입을 동기화합니다. API 인터페이스가 변경되면 프론트엔드에서 즉시 타입 오류를 확인할 수 있습니다.
  </Accordion>
  
  <Accordion title="타입 안전 쿼리 빌더 (Puri)">
    완전한 타입 추론을 지원하는 쿼리 빌더입니다. 테이블 스키마를 기반으로 SELECT, WHERE, JOIN 등 모든 쿼리 작성 중 타입을 추론합니다.
  </Accordion>
  
  <Accordion title="자동 마이그레이션">
    엔티티 정의와 실제 DB 스키마를 비교하여 마이그레이션 코드를 자동 생성합니다. 안전한 스키마 변경 관리를 제공합니다.
  </Accordion>
</AccordionGroup>
