# i18n (다국어 지원)

## 설정

`sonamu.config.ts`:

```typescript
export default defineConfig({
  i18n: {
    defaultLocale: "ko",
    supportedLocales: ["ko", "en"],
  },
  // ...
});
```

## 파일 구조

```
packages/api/src/i18n/
├── ko.ts           # 기본 locale (defaultLocale)
├── en.ts           # 추가 locale
└── sd.generated.ts # 자동 생성 (pnpm sync)
```

## 딕셔너리 파일

### 기본 locale (ko.ts)

```typescript
import { createFormat, josa } from "sonamu/dict";

const format = createFormat("ko");

export default {
  "common.save": "저장",
  "common.cancel": "취소",
  "validation.required": (field: string) => `${josa(field, "은는")} 필수입니다`,
  "common.results": (count: number) => `${count}개 결과`,
  test: (date: Date) => format.date(date),
} as const;
```

### 추가 locale (en.ts)

```typescript
import { plural } from "sonamu/dict";
import { defineLocale } from "./sd.generated";

export default defineLocale({
  "common.save": "Save",
  "common.cancel": "Cancel",
  "validation.required": (field: string) => `${field} is required`,
  "common.results": (count: number) =>
    plural(count, { one: `${count} result`, other: `${count} results` }),
});
```

## SD 함수 사용

### 기본 사용

```typescript
import { SD } from "@/i18n/sd.generated";

// 단순 문자열
SD("common.save");  // → "저장" (ko) / "Save" (en)

// 함수형 (파라미터)
SD("validation.required")("이메일");  // → "이메일은 필수입니다"
SD("common.results")(5);  // → "5개 결과" (ko) / "5 results" (en)
```

### 특정 locale 강제

```typescript
const EN = SD.locale("en");
EN("common.save");  // → "Save" (항상 영어)
```

### Enum 라벨

```typescript
// entity.json에 정의된 enum 라벨
SD.enumLabels("ProjectStatus")["in_progress"];  // → "진행중"
```

## 헬퍼 함수

### plural (복수형)

```typescript
import { plural } from "sonamu/dict";

// 영어에서 단수/복수 처리
plural(count, {
  zero: "No items",     // count === 0
  one: "1 item",        // count === 1
  other: `${count} items`,  // 그 외
});
```

### josa (한국어 조사)

```typescript
import { josa } from "sonamu/dict";

josa("이메일", "은는");  // → "이메일은"
josa("이름", "이가");    // → "이름이"
josa("파일", "을를");    // → "파일을"
josa("회사", "과와");    // → "회사와"
josa("서울", "으로");    // → "서울로"
```

### createFormat (숫자/날짜 포맷)

```typescript
import { createFormat } from "sonamu/dict";

const format = createFormat("ko");
format.number(1234567);  // → "1,234,567"
format.date(new Date()); // → "2024. 1. 15."
```

## Entity 연동

Entity의 title, prop desc, enum label이 자동으로 딕셔너리에 포함됨.

```
entity.{EntityId}              → Entity 타이틀
entity.{EntityId}.{propName}   → 속성 설명
enum.{EnumId}.{value}          → Enum 값 라벨
```

예시:
```typescript
SD("entity.User");           // → "사용자"
SD("entity.User.email");     // → "이메일"
SD("enum.UserRole.admin");   // → "관리자"
```

## localizedColumn

DB에 locale별 컬럼이 있을 때 현재 locale에 맞는 값 반환:

```typescript
import { localizedColumn } from "@/i18n/sd.generated";

// DB: { name: "태그", name_ko: "태그", name_en: "Tag" }
localizedColumn(tag, "name");  // → "태그" (ko) / "Tag" (en)
```

## Sonamu UI 관리

`http://localhost:34900/sonamu-ui` → i18n 탭에서:
- 딕셔너리 조회/수정
- 키 추가/삭제
- Excel import/export
- 미사용 키 검사

## 키 네이밍 규칙

| 패턴 | 용도 | 예시 |
|------|------|------|
| `common.*` | 공통 UI 텍스트 | `common.save`, `common.cancel` |
| `error.*` | 에러 메시지 | `error.notFound`, `error.forbidden` |
| `validation.*` | 유효성 검사 | `validation.required`, `validation.email` |
| `entity.*` | Entity 관련 | `entity.User`, `entity.User.email` |
| `enum.*` | Enum 라벨 | `enum.UserRole.admin` |
| `menu.*` | 메뉴/네비게이션 | `menu.home`, `menu.settings` |
| `rc.*` | react-components 내장 | `rc.pagination.next` |
