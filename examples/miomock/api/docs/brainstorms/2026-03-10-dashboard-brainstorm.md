# Brainstorm: 경영진 대시보드

**Date:** 2026-03-10
**Status:** Complete
**Domain:** dashboard (새 도메인)

---

## What We're Building

경영진이 조직과 프로젝트 현황을 한눈에 파악할 수 있는 대시보드 페이지.
현재 `/admin/` 인덱스 페이지는 유저 정보 + 네비게이션 버튼만 있는 플레이스홀더 상태이며, 이를 실질적인 대시보드로 교체한다.

### 핵심 섹션 (4개)

1. **조직 현황 카드** — 회사 수, 부서 수, 직원 수 (숫자 카드 3개)
2. **프로젝트 현황** — 상태별 카운트 카드 (기획/진행/완료/취소) + 진행중 프로젝트 TOP 5 테이블 (이름, 마감일, 마일스톤 진행률)
3. **문서 현황 카드** — 총 문서 수 + 상태별 카운트 (draft/published/archived)
4. **최근 활동 타임라인** — audit log 기반 날짜별 그룹핑 (오늘/어제/...) 최근 20건, "더보기" → audit-log 페이지 이동

### 빈 상태 처리
- 데이터 0건: "아직 등록된 [엔티티]이 없습니다" 메시지
- 진행중 프로젝트 5개 미만: 있는 만큼만 표시

---

## Why This Approach

### 시각화: 숫자 카드 + 테이블/리스트 중심
- 차트 라이브러리 의존 없이 기존 sonamu-kit 컴포넌트(Card, Table, Badge) 재활용
- 경영진 Overview 목적에 맞는 간결한 정보 전달
- 구현 복잡도 낮음

### API 설계: 하이브리드 (전용 API + 기존 메서드 재사용)
- 전용 API 엔드포인트 1개 (`dashboard/stats`)
- 내부에서 기존 모델의 findMany 등을 `this.xxx()` 패턴으로 재사용
- 활동 타임라인은 기존 AuditLog findMany 활용

### 필터: 활동 타임라인에 기간 필터만
- 카운트 메트릭은 항상 전체 데이터 기준
- 활동 타임라인만 7일/30일/전체 기간 선택 가능

### 새로고침: 페이지 로드 시
- TanStack Query로 페이지 진입/포커스 시 자동 fetch
- staleTime으로 캐시 제어
- 폴링이나 실시간 업데이트 불필요

## Key Decisions

| # | 결정 | 선택 | 이유 |
|---|------|------|------|
| 1 | 대시보드 사용자 | 경영진 Overview | high-level 메트릭 중심 |
| 2 | 핵심 메트릭 | 조직 + 프로젝트 + 문서 + 활동 4개 전부 | 종합적 현황 파악 |
| 3 | 시각화 방식 | 숫자 카드 + 테이블/리스트 | 차트 라이브러리 불필요, 단순 구현 |
| 4 | 활동 피드 형태 | 날짜별 그룹 타임라인 | 시간 흐름 직관적 |
| 5 | API 설계 | 하이브리드 (전용 API + 내부 재사용) | 팀 패턴 준수, 네트워크 효율적 |
| 6 | 필터 | 활동 타임라인에 기간 필터만 | YAGNI, 카운트는 항상 전체 |
| 7 | 새로고침 | 페이지 로드 시 (TanStack Query) | 단순, 서버 부하 최소 |
| 8 | 프로젝트 상세 | 상태별 카운트 + 진행중 TOP 5 + 마일스톤 진행률 | 전체 현황 + 액션 가능 정보 |
| 9 | 엔티티 설계 | 별도 엔티티 없이 전용 API 라우트 | 데이터는 기존 모델에 이미 존재 |
| 10 | 더보기 동작 | audit-log 페이지 이동 | 기존 페이지 재활용 |
| 11 | 활동 건수 | 최근 20건 | 대시보드 적정 분량 |
